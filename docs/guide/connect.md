## Шаги

<div class="grid cards asterion-cards" markdown>

-   :material-numeric-1-circle:{ .asterion-icon }

    **Запустите Minecraft Java Edition**

    ---

    Нужна версия игры, которая подходит серверу. Актуальная версия указана на [главной странице](../index.md).

-   :material-numeric-2-circle:{ .asterion-icon }

    **Добавьте сервер**

    ---

    «Сетевая игра» → «Добавить сервер», адрес: `asterion.20tps.ru`.

-   :material-numeric-3-circle:{ .asterion-icon }

    **Зарегистрируйтесь**

    ---

    При первом входе введите `/register <пароль> <пароль>`. В следующие разы входите командой `/login <пароль>`.

-   :material-numeric-4-circle:{ .asterion-icon }

    **Прочитайте правила**

    ---

    Особенно список [запрещённых модов](../rules/forbidden-mods.md): проверьте свою сборку до входа.

</div>
