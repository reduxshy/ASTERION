## Невидимые рамки

<div class="asterion-info-panel" markdown>

<div class="asterion-info-heading" markdown>

:material-image-frame: **Невидимые рамки для предметов**

<span>Датапак Better Item Frames. Работает и с обычными, и со светящимися рамками</span>

</div>

Позволяет скрыть саму рамку, оставив видимым только предмет в ней. Удобно для красивых построек: надписи, витрины, украшения.

Во всех действиях нужно **присесть** (Shift) и нажать **правой кнопкой мыши** по рамке с нужным предметом в руке.

| Предмет в руке | Что происходит |
|:--|:--|
| **Ножницы** | Рамка становится невидимой |
| **Щётка** | Рамка снова становится видимой |
| **Стеклянная панель** | Предмет в рамке фиксируется: его нельзя случайно повернуть |

</div>

![Невидимые рамки: ножницы, щётка и стеклянная панель](../assets/crafts/invisible-frames.png){ .asterion-shot loading=lazy }

!!! tip "Как снова разрешить вращение"

    Чтобы убрать фиксацию поворота, сломайте рамку и поставьте её заново.

## Невидимый свет

<div class="asterion-info-panel" markdown>

<div class="asterion-info-heading" markdown>

:material-lightbulb-on: **Невидимый источник света**

<span>Датапак на невидимый свет. Рецепт крафта для выживания</span>

</div>

Блок света не виден в мире, но освещает пространство вокруг. Подходит для скрытой подсветки построек, пещер и интерьеров без видимых факелов и ламп.

| Ряд | Слот 1 | Слот 2 | Слот 3 |
|:--|:--|:--|:--|
| **1** | | | |
| **2** | | Стекло | Факел |
| **3** | | | |

Результат: **блок света**.

</div>

![Рецепт невидимого света: стекло и факел](../assets/crafts/invisible-light.png){ .asterion-shot .asterion-recipe loading=lazy }

!!! tip "Как увидеть поставленные блоки света"

    Возьмите блок света в руку: расположенные рядом невидимые блоки света станут заметны.

## Напитки

<div class="asterion-info-panel" markdown>

<div class="asterion-info-heading" markdown>

:material-glass-mug-variant: **Варка напитков**

<span>Плагин BreweryX</span>

</div>

На сервере можно варить алкогольные напитки, после которых персонаж пьянеет. Рецепты задаются сервером, а хорошие напитки требуют правильных ингредиентов и процесса варки: подбирать их приходится экспериментом.

| Команда | Что делает |
|:--|:--|
| `/brew help` | Справка по плагину |
| `/brew info` | Показывает ваше состояние опьянения |

</div>
