# Справочник

Здесь будут собраны подтверждённые инструкции для игроков ASTERION.

На данный момент точные игровые команды, правила телепортации, экономика, система приватов и привилегии не подтверждены. Список плагинов сам по себе не гарантирует, что конкретная функция включена или доступна всем игрокам.
