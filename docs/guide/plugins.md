    ---

    ---

    Эмоции и анимации игрока.

    ---

    TPS и пинг в списке игроков.

## Защита и администрирование

<div class="asterion-info-panel" markdown>

<div class="asterion-info-heading" markdown>

:material-shield-lock: **Для администрации**

<span>Эти плагины работают в фоне</span>

</div>

| Плагин | Назначение |
|:--|:--|
| **LuckPerms** | Управление правами и группами |
| **CoreProtect** | Журнал действий с блоками и откат гриферства |
| **MinerTrack** | Отслеживание добычи руд |
| **XaeroForceDisabler** | Ограничение функций Xaero's карт на сервере |
| **Chunky** | Предварительная генерация мира |
| **Multiverse Core и Portals** | Несколько миров и порталы между ними |
| **SkinsRestorer** | Восстановление скинов игроков |
| **DiscordSRV** | Связь игрового чата с Discord |
| **TAB** | Оформление списка игроков |
| **PlaceholderAPI** | Подстановка данных в другие плагины |
| **packetevents** | Библиотека для других плагинов |

</div>
