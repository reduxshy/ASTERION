# Подключение к ASTERION

## Данные сервера

| Параметр | Значение |
|---|---|
| Адрес | `asterion.20tps.ru` |
| Ядро | Purpur |
| Указанная версия | `26.2` |

## Как подключиться

1. Запустите Minecraft Java Edition.
2. Откройте **Сетевая игра**.
3. Нажмите **Добавить сервер**.
4. В поле адреса укажите `asterion.20tps.ru`.
5. Сохраните настройки и попробуйте подключиться.


## Если не удаётся подключиться

- Проверьте адрес `asterion.20tps.ru`.
- Уточните совместимую версию клиента у администрации.
- Сохраните текст ошибки или сделайте скриншот.
- Обратитесь в [Discord ASTERION](https://discord.gg/FGb8aVEJQ).

Список обязательных клиентских модов и дополнительные требования пока не предоставлены.
