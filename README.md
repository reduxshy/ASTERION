# ASTERION Wiki

Русскоязычная вики Minecraft-сервера ASTERION на MkDocs Material.

## Публикация через GitHub Pages

1. Добавьте содержимое этой папки в корень репозитория `reduxshy/ASTERION.github.io`.
2. Убедитесь, что основная ветка называется `main`. Если название другое, измените ветку в `.github/workflows/ci.yml`.
3. В GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
5. Отправьте изменения в репозиторий и откройте вкладку **Actions**.
6. После успешного workflow сайт должен появиться по адресу:
   https://reduxshy.github.io/ASTERION.github.io/

## Локальный просмотр

```bash
python -m pip install -r requirements.txt
python -m mkdocs serve
```

## Важно

Версия `26.2` записана как предоставленное обозначение версии сервера/Minecraft; уточните, к чему именно относится номер, прежде чем указывать его как официальную версию клиента. Наличие плагинов и датапаков взято из предоставленных скриншотов. Описание их функций намеренно ограничено тем, что можно достоверно вывести из названий.
